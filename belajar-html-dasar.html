01 — DASAR STRUKTUR

Anatomi HTML

Setiap halaman HTML memiliki struktur dasar. Browser membaca struktur ini untuk memahami isi halaman.

<!DOCTYPE html>
<html lang="id">
  <head>
    <title>Judul Halaman</title>
  </head>
  <body>
    <h1>Halo, dunia!</h1>
  </body>
</html>

<!DOCTYPE html>

Memberi tahu browser bahwa dokumen menggunakan HTML5.

<html>

Elemen utama yang membungkus seluruh dokumen HTML.

<head>

Berisi informasi halaman, seperti judul dan metadata.

<body>

Berisi semua konten yang terlihat oleh pengunjung.

02 — KONTEN TEKS

Tag Teks & Judul

Gunakan heading untuk judul, paragraf untuk teks biasa, dan tag formatting untuk memberi penekanan.

<h1>Judul Utama</h1>
<h2>Subjudul</h2>
<p>Ini adalah sebuah paragraf.</p>
<p>Teks bisa dibuat <b>tebal</b> atau <i>miring</i>.</p>

Judul Utama

Subjudul

Ini adalah sebuah paragraf.

Teks bisa dibuat tebal atau miring.

Membuat daftar

<ul> membuat daftar tanpa urutan, sedangkan <ol> membuat daftar bernomor. Setiap item memakai <li>.

<ul>
  <li>Keyboard</li>
  <li>Mouse</li>
</ul>

<ol>
  <li>Buka editor kode</li>
  <li>Buat file HTML</li>
</ol>

03 — GAMBAR & TAUTAN

Media & Link

Tag <img> menampilkan gambar. Atribut src berisi lokasi gambar dan alt menjelaskan gambar bila tidak dapat dimuat atau dibaca pembaca layar.

<img src="gambar-belajar.jpg" alt="Siswa sedang belajar HTML">

Tag <a> digunakan untuk membuat tautan. Atribut href menentukan alamat tujuan.
